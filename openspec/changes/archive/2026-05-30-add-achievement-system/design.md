## Context

当前应用有6个页面、SQLite数据库、评分计算器。学习完成后页面显示分数和反馈，但没有成就系统和可分享的内容。

## Goals / Non-Goals

**Goals:**
- 成就系统：追踪学习连续天数、知识点掌握等级、知识点完成数量等，在进度看板展示
- 证书：完成课程所有知识点后生成可展示的证书
- 分享：支持将成就卡片、证书、学习报告分享到系统分享面板

**Non-Goals:**
- 不与社交平台API直接集成（使用系统分享面板）
- 不涉及图片编辑或复杂证书模板

## Decisions

- **成就存储**: 存储在 preferences 中（轻量级，无需新增 DB 表）
- **证书数据**: 存储在 preferences 中，证书内容实时生成
- **分享方式**: 使用 HarmonyOS `@ohos.share` 或系统 `Want` 分享文本/文件
- **成就类型**:
  - 学习连续天数（7天/14天/30天）
  - 掌握等级成就（首次达到优秀/良好）
  - 知识点完成成就（首次完成1/5/10/25/50个知识点）
  - 课程完成成就（首次完成1/3/5门课程）
- **证书触发**: 完成课程所有知识点（所有三步均完成）时自动生成

## Risks / Trade-offs

- 模拟器可能不支持系统分享面板 → 分享功能会自动降级为复制到剪贴板
- 成就数据存储在 preferences 中，清除应用数据会丢失 → 可接受，成就可重新获得
