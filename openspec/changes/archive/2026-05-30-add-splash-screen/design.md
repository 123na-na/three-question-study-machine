## Context

当前 `Index.ets` 作为启动入口页面，仅显示文字标题和加载动画，数据初始化逻辑与 UI 混合在一起。改造为品牌启动页后，需在展示品牌形象的同时完成数据预加载，加载完成后自动导航到首页或引导页。

## Goals / Non-Goals

**Goals:**
- 展示品牌 Logo（`foreground.png`）、应用名"问枢"、标语"是什么 → 为什么 → 怎么用"
- 后台预加载数据库、示例课程、引导状态检查
- 加载完成后自动跳转
- 数据加载期间显示 Loading 动画
- 加载失败时显示错误页并提供重试按钮

**Non-Goals:**
- 不涉及网络资源预加载（仅本地数据）
- 不涉及权限预申请

## Decisions

- **数据预加载串行执行**: 数据库初始化 → 示例课程加载 → 引导状态检查，保持现有逻辑
- **共用同一页面**: 不单独创建 SplashPage，直接在 `Index.ets` 内通过 `@State` 状态管理加载/错误/引导三种视图
- **Logo 使用 `$r('app.media.foreground')`**: 引用已替换的品牌图标资源

## Risks / Trade-offs

- 启动阶段异常（如数据库初始化失败）→ 显示错误页 + 重试按钮，不会白屏
- 长时间停留在启动页 → LoadingProgress 提示用户正在初始化，不会无响应
