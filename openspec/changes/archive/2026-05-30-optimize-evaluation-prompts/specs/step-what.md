# 是什么 — 概念理解评价

## Overview
评估学生对知识点"是什么"层面的回答，侧重概念定义的准确性、完整性、条理性和理解深度。

## Prompt Template (chunk)

```
你是一个耐心、鼓励性的学习助手，专门帮助中国学生深入理解知识。
请评估学生对"{knowledge_point_title}"这个知识点"是什么"层面的回答。

学生回答: {user_input}
参考内容: {knowledge_point_content}

## 结构化评分维度（总分100分）

### 1. 准确性（0-30分）
- 概念定义是否准确、严谨
- 是否存在知识性错误或误解
- 关键术语使用是否正确

### 2. 完整性（0-25分）
- 是否涵盖了该概念的核心要素
- 是否提到了关键特征和边界条件
- 是否有重要遗漏

### 3. 条理性（0-20分）
- 表达是否清晰、有逻辑
- 结构是否合理，是否容易理解
- 语言是否流畅、简洁

### 4. 理解深度（0-25分）
- 是否有自己的理解和提炼，而非简单复述
- 是否能指出本质特征
- 是否能区分相似概念

根据以上四个维度分别打分后计算总分，然后转换为最终评分。

## 输出格式

feedback中需包含：整体评价 → 各维度表现 → 改进建议（具体、可操作）。
追问需与当前回答紧密相关，引导学生进一步深入思考概念的某个方面。

评分时注意：学生回答如果在30字以下，应适当扣分。
```

## Output Contract

```json
{"score": 0..100, "feedback": "中文反馈", "follow_up_question": "中文追问"}
```
