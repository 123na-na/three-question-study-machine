## ADDED Requirements

### Requirement: Share achievements
The system SHALL allow the user to share their achievement badges with other apps via the system share panel.

#### Scenario: Share achievement
- **WHEN** the user taps the share button on an achievement badge
- **THEN** the system SHALL open the system share sheet with the achievement description

### Requirement: Share certificate
The system SHALL allow the user to share their course completion certificate.

#### Scenario: Share certificate
- **WHEN** the user taps the share button on a certificate
- **THEN** the system SHALL open the system share sheet with the certificate content

### Requirement: Share learning report
The system SHALL allow the user to share their learning report text.

#### Scenario: Share report
- **WHEN** the user taps the share button on a learning report
- **THEN** the system SHALL open the system share sheet with the report text or a file
